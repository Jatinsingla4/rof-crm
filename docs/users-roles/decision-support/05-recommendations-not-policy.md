# Recommendations for the open decisions (NOT approved owner policy)

**These are my recommendations, written to help the owner decide. They are not decisions and not policy. Nothing in this file is implemented or assumed anywhere.**
Where the plan already contains a "recommended design" that is the plan's recommendation, quoted as such; my own view is labelled "my recommendation". The owner's answer overrides every line.
Basis: the decision-support documents `02` to `04` and the verification of the code at HEAD. Plan wording is from the v6 copy (v7 is missing, see `00-plan-integrity.md`).
