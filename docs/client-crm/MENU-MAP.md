# Client CRM: menu map (read from the live menu, 212 links)

System: "REALESTATE MANAGER" (4QT Reality, ASP.NET WebForms), http://52.66.133.208/ROF/Home.aspx. Dashboard shows 5 panels: Pending Cheques, Demand Status, Daily Status, Parking Detail, Forthcoming Due.
Rule for this work: look only; the one exception is a dummy project the owner allowed us to create. No real customer data is changed.

## Set Master
- Set Up: Area Type, Currency, Customer Profession, Country, Letter Head Format
- Bank Master: Company Bank, Customer Bank, Loan Bank
- Employee: Department, Report, Set Manager, Team Master, Set Team Head, Team Head Detail, Employee Tree
- Documents: Document Type, Document Dispatch Master
- Security: Password/Code. Role and Menu: Role Category Wise Page Hierarchy

## Set Projects
- Create Project: Add Tower/Plot, Add Base Floor, Floor Creation, Unit Type, Floor Wise Unit Allocation, Address Owner, Unit Location; Pre-Attach PLC and Other Charges
- Edit Project: Tower, Floor, No. of Plot/Villa, Unit Address/Location, Change Unit Area (individual), Unit Wise Area (+ report)
- Payment plan: Payment Plan Creation, Stage Master, Set Booking Amount, Create Installment, Customer Wise Timely Discount; Edit Installment / PLC / Other Charge / Personal Installment; View Raised Demand Stage, View Payment Plan
- Setup: Reminder Days, Demand Format Customization
- Charge Master: Other Charge, PLC, IFMS (interest free maintenance)
- Add-on Charges: Master, Set (single and bulk), Cancel, Waive-off
- Tax: Tax Master, Tax Information, Tax Configuration Report, Completion Certificate Master
- GST: User Rights, Configuration, ITC Configuration, Invoice Prefix, Customer Wise GST Discount, GST Number Configuration
- Automated/Manual switches: Booking Authentication, Receipt No., Registration No., Transfer Authentication
- Project Set Up: Customer Classification, Project Configuration Detail. Set Rate: Change Rate, Change Charges Rate, Rate Report

## Broker
Application, View/Edit, Broker Project Mapping, Sub Broker Mapping, Address Label. Reports: Summary, Summary Sold-Unit, Broker, Broker Wise Booking, Broker Hierarchy

## Application (the sale flow)
- Booking Form. Unit Shifting: Shift Units, Unit Shift Report. Approval Status: Booking Status, Editing Status
- Booking tools: Head Wise Cost, Applicant Addition/Deletion, Edit Customer Address, Customer Register
- Allotment: Allotment Form, Allotment Letter, Allotment Cancellation, RERA Agreement, Allotment Information, Conveyance Deed Date; Allotment and Agreement Status, Pending Allotment Ageing, Allotment Cancel Report
- Receipts: Receipt Generation, Receipt Print; Journal Entry, Debit/Credit, Journal Report, JV/Dr/Cr/Refund Reversal; Cancel Receipt Report; TDS Challan Report, Assign Receipt Challan, Upload TDS Challan
- Demand Raise: Stage Wise, Tower Wise, Customer Wise, Installment Wise, Unit/Stage Wise, Demand Unraise
- Printing: Welcome, Demand, Installment Wise Demand Status, Print Demand Manually, Email Notification, ATS, TPA, Applicant Ledger, User Define Letters, Address Labels, Conveyance Deed
- GST invoicing: Customer Opening, Assigned ITC, Invoice Generation / Manual / Reversal / Cancellation / Against Advance, Credit/Debit Against Invoice, Pending Invoice; reports: Invoice Details, Opening Balance, Invoice Receipts, Month Wise, HSN and Charge Wise
- Surrender/Cancellation: Application, Report, Restore

## Reports
- Inventory: Project Details; Unit Status (project, tower, unit type), Inventory Summary, Availability Sheet; Unit Wise PLC, Sold/Available Area Wise, Unit Cost
- Applicant: Payment File, Master Report, History, Search, Birthday, Customer Detail, Classification, Names, Increase Area
- Collection: Project, Collection, Customer Wise, Customer Balance, Charges Wise (vertical/horizontal), Receipt Wise, Tower vs Unit Type, Against Dues, Chart, Year/Month Wise
- Dues: Customer, Due Report, Date Wise, Stage/Tower/Plan wise, Percentage wise (3), Ageing (2), Month Wise, Forecasting, Installment/Head Wise
- Charge detail: Other Charge, Parking, IFMS, PLC, Extra Charge, Customer PLC, Customer Alteration, Extra Addon

## Parking
Parking Type Master, Inventory Master, Assign Parking, Inventory Report. Header: Task Assignment, Reminder.
