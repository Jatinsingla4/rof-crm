# Captured from the client CRM, part 13: Set Projects, tab by tab (View screens of project ROF AMBLISS, the richer project)

- **Unit Type Creation**: same columns as part 9 (Group, Unit Type "Group-(carpet area Sq. Ft.)", Super / Build Up / Carpet / UDSL / Plot / Balcony Area, Unit, Rate, Construction Cost, UDSL Cost, Type, Area Type, Date, Effective Rate, Unit of Measurement, Plot Area Measurement, Show On Payment File, Description, Edit, Delete, Download). A button **Add Group** adds a group name for the project. Several unit types share one group (4 / 4G / 4P of "Type 4 (2BHK)" differ in balcony area).
- **Edit Tower** (Project, Tower, **Total Floor**, New Name of Tower, Prefix Name Of Unit Address, Sort Order): AMBLISS towers T1 to T7, 15 floors each. **Edit Floor** (Tower, Floor, Unit count, New Floor name): "GROUND FLOOR (5 units), 1st FLOOR (8), 2nd FLOOR (8), 3rd FLOOR ..." (floor names with ordinal text, unit count per floor, rename box).
- **Floor Wise Unit Allocation / Pre-Attach PLC / Pre-Attach Other Charges / Address Owner / Edit Unit Address / Change No. of Plot or Villa / Unit Wise Area**: filter screens (project, tower, floor, unit type ...) that list units after Fetch; Pre-Attach attaches a PLC or other charge to many units of a tower in one go.
- **Payment Plan Creation** (list): Payment Plan, Plan Type, Discount %, Discount Calculate, Type, Discount (Per Area), Timely Discount, Status Active, Edit, Delete. AMBLISS has plans "PAYMENT PLAN" and "CONSTRUCTION LINKED PAYMENT PLAN". After saving a plan the system asks "Do you want to create its installment?" (Yes / No).
- **View Payment Plan (AMBLISS)**: grid Installment Name, **BSP %, and one % column per other charge** (Ad Charge, Balcony Charge, Restoration Charge, Scooter Parking). Example rows: "AT THE TIME OF SUBMISSION OF APPLICATION" BSP 5.00 / Balcony 5.00; "WITHIN 15 DAYS FROM THE DATE OF RECEIPT/..." 20.00 / 20.00; "ON THE COMPLETION OF SUBSTRUCTURE" 12.50 / 12.50; "ON COMPLETION OF 20% OF SUPERSTRUCTURE" 12.50 with Ad, Balcony, Restoration and Parking at 100.00 (those charges fall due in full at that installment). So **a plan splits every charge across installments by its own percentages**; Edit PLC Charge / Edit Other Charge installments edit those columns.
- **Edit Personal Installment / Personalise Installment**: lists customers (Reg No, Name, Total number of installments (9), Unit Type, Unit Address, Allotment Date, link "Edit Installment") and a per-customer plan pick list; a customer can be moved to a different plan or get own installments.
- **Raised Demand Stage**: per stage, the towers it was raised for with **Installment Date and Forecasting Date** (tower-wise demand raise: same date for towers T1 to T7).
- **Reminder Days Configuration (AMBLISS)**: Reminder Name, Days, Prefix, Rank: **Reminder, 10 days, R1, rank 1; Cancellation Letter, 20 days, R2, rank 3; Final Opportunity Letter, 45 days, prefix T, rank 2**. So a reminder rule is a **letter step** of the dues ladder: how many days after the demand, its short prefix and its rank (the order is not the order of the days).
- **Other Charge master (AMBLISS)**: Balcony Charge (Fix 1,00,000), Scooter Parking (qty 798, inventory based, mandatory, parking area 1,000), Restoration Charge (50,000), Ad Charge (30,000); full column list in part 6. **Project Configuration Detail** repeats unit types, the charge masters and the plans with number of installments on one screen (read-only summary).
- **Extra Add On Charge Master (AMBLISS)**: columns Charge, Charge Type, Amount Type, Amount, **Apply Date Type** (Possession / Customer Wise Date), **Calculate Rate Type** (Old Area), **Is Include In Dues** (Yes). Rows: Cheque Bounce Charge (Other, Fix, 500, apply on Possession), Restoration Charges (Fix 50,000, customer wise date), Transfer Charges (Fix 1,00,000, customer wise date).
- **Tax Master**: ROF AMBLISS, effective 08/07/2004, Receipt Basis, code "0%_OLD", all zero (legacy service tax). Tax Information and Tax Configuration Report show the same rows.
- **Completion Certificate Master**: one row per tower with a Completion Date (blank); LOG button shows the change log.
- **Change Rate** (per unit type: Rate and Date, with history) and **Rate Report** (Unit Type, Unit Rate, Date): rates have an effective date, e.g. 4,200 from 14/07/2022 for every 643.041 sq ft type. **Change Charges Rate**: same for PLC / Other / IFMS.
- **Transfer Authentication** (and the other three switches): one row per project, Mode Automatic / Manual, Edit.
- Empty for AMBLISS too: Set Booking Amount, PLC master, IFMS master, Customer Classification, Invoice Prefix, GST Number, Address Owner, Unit Location.
- **Change No. of Plot/Villa** (plot projects such as ROF INSIGNIA SOUK, ROF ICON): a plotted project has **no tower or floor**; it is a list of unit types (e.g. "127.673 SQ.YDS") with Total Unit and a box **Add On Unit** to add more plots of that type; UPDATE / CLOSE.
- **Floor Wise Unit Allocation**: the project drop-down was empty for this login, so the screen could not be read beyond its labels (Project, Tower, Floor, Fetch, Preview Address Order, Save, Copy Address From).
- Not readable with this login: Floor Wise Unit Allocation results, Unit Wise Area results, GST Configuration tab contents for these projects.
