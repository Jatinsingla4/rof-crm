## 🛠️ Technical Specifications

### Technology Stack
- **Language:** TypeScript
- **Database:** PostgreSQL (existing)
- **Architecture:** Direct database seeding (no API calls)
- **Pattern:** Factory/Fixture approach with realistic data
- **Idempotency:** ON CONFLICT DO NOTHING (safe re-runs)

### Data Relationships
```
Projects
  ├── Units (50-120)
  ├── Consumers (15-60)
  │   ├── Allocations
  │   │   ├── Receipts (payment history)
  │   │   └── Demand Letters (overdue)
  │   └── Waitlist (unallocated)
  └── Milestones (13 per project)
```

### Payment Schedule Implementation
**AHP-Compliant (Haryana Affordable Housing Policy):**
```
Total Cost: ₹46 Crores
Booking (10%):     ₹3.5 Crores
Allotment (20%):   ₹7 Crores (within 15 days)
Installment 1-6 (12.5% each): ₹4.375 Crores each
```

### Penal Interest Calculation
- **Rate:** 11.10% per annum (SBI MCLR + 2%)
- **Per HRERA Rule 15:** Auto-calculated for overdue amounts
- **Applied:** To demand letters and payment dashboards

## 📞 Troubleshooting

| Problem | Solution |
|---------|----------|
| No data visible | Run: `npm run seed:active` in `/packages/api` |
| Blank screens | Hard refresh: `Ctrl+Shift+R` (Chrome/Firefox) |
| API errors | Ensure backend running: `npm run dev` in `/packages/api` |
| Database connection failed | Check `.env` settings (DB_HOST, DB_USER, etc.) |
| Slow loading | Normal with 40+ consumers; explain caching strategy |
