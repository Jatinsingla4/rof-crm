┌─ IF SOMETHING BREAKS ─────────────────────────────────────────────────────────┐

     → Clear cookies: Settings > Clear browsing data

  🔴 No Data Visible?

     → Re-run seed: npm run seed:active
     → Wait 10 seconds for UI to reload

            We'll implement caching for production."
